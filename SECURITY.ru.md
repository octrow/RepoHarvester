# Политика безопасности

## Поддерживаемые версии

Исправления выходят только для последнего релиза.

## Как сообщить об уязвимости

Не открывайте публичный issue. Сообщите приватно через
[GitHub security advisories](https://github.com/octrow/RepoHarvester/security/advisories/new).
Отвечу в течение недели и напишу, что будет дальше.

RepoHarvester запускает `git` с переданным URL и читает локальные файлы. Поэтому интереснее всего такие случаи:
внедрение аргументов через специально составленный URL, выход за пределы клонированного репозитория
или запись результата не в ту папку.
